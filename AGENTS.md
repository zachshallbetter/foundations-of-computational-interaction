# Agent guide

This repository keeps agent guidance in two files, split by kind. Read both before working here.

| File | Covers |
|---|---|
| **[`.agents/AGENTS.md`](.agents/AGENTS.md)** | **Research doctrine** — the guiding principle, the three architectural layers, the epistemological questions, editorial language rules, example-identity rules, and publication quality gates |
| **[`CLAUDE.md`](CLAUDE.md)** | **Operations** — layout, authority order, the verification gate, CI, per-layer versioning and changelogs, branch/commit conventions, and research-claim practices |

The split is deliberate: doctrine constrains *what may be claimed and how it is written*; operations
constrain *how changes are verified and recorded*. Neither substitutes for the other.

Start with [`CLAUDE.md`](CLAUDE.md) if you are making a change; start with
[`.agents/AGENTS.md`](.agents/AGENTS.md) if you are writing or editing the corpus.
