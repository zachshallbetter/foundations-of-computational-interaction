# Support

Foundations of Computational Interaction is maintained by one person. This page says what that means in practice.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/foundations-of-computational-interaction/issues/new/choose).
  Use the bug report or feature request form so the maintainer has what is needed to act.
- **Response time:** best-effort, with no SLA. Nobody is on call, and a reply can take a while.
- **Security reports:** do not open a public issue. Follow [`SECURITY.md`](SECURITY.md), which uses
  GitHub private vulnerability reporting.
- **Versioning:** Theory, specifications, software and examples version independently; the policy is in [`app/VERSIONING.md`](app/VERSIONING.md). A shared number never implies cross-layer conformance.
